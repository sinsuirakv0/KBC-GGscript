# 設計

## データ変換

`tools/build-data.ps1` は元の `unit001.csv` を `data/units/unit000.csv` へ変換する。各形態は117列に補完し、ネイティブローダーで確認した既定値と倍率を適用済みの値として保存する。名前と形態名は `resLocal/Unit_ExplanationNNN_ja.csv` から `unit-names.csv` へ抽出する。

| CSV列 | 変換 |
| --- | --- |
| 2, 7 | 2倍 |
| 4, 5, 9, 44, 45 | 4倍 |
| 6 | 100倍 |
| 55, 57, 66, 110 | 未指定時 -1 |
| 63 | 未指定時 1 |

## アドレス決定

Luaは基礎になるネコ第1形態を基点にする。C_BSSから`5000`を検索してアドレス順に並べ、最初から順にネコの第1〜第3形態の先頭12列と照合する。一致したレコード先頭を `unit000 / 第1形態 / CSV列0` のアドレスとして採用する。

選択したユニットの列アドレスは次で求める。

```text
tableStart + unitId * 0x750 + form * 0x1d4 + column * 4
```

`tableStart` はネコ第1形態のCSV列0、`unitId` と `form` はともにゼロ始まりである。これにより、対象ユニットを毎回検索せずに変更できる。

## UI

最初に「一覧から選ぶ」「キャラ名で検索」を選ぶ。一覧では `0〜99`、`100〜199` のように100件単位で絞り込んでからキャラを選び、続いて形態を選ぶ。
