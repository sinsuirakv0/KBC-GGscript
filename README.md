# KBC-GGscript

にゃんこ大戦争向けの GameGuardian Lua スクリプトです。キャラ解放/削除・レベル・現在形態、ユニットステータス、施設レベルを端末上で確認・編集できます。

> [!WARNING]
> 実行前に必ずセーブデータをバックアップしてください。メモリ編集はゲームの利用規約、オンライン機能、端末環境に影響する場合があります。利用者自身の端末・データで、適用される規約と法律の範囲内で使用してください。

## できること

- キャラごとの解放/削除、Lv・プラス値、現在形態の変更
- キャラステータスの変更・初期化・保存・読み込み
- 施設レベル変更
- 全キャラを対象にした操作

形態変更は現在表示する形態を切り替える機能です。形態の解放はできません。

## 必要なもの

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| Android端末またはAndroid仮想環境 | 必須 | にゃんこ大戦争を起動できる環境 |
| KBC GameGuardian | 必須 | Luaスクリプトを実行するアプリ。本リポジトリには同梱しません。 |
| このリポジトリ一式 | 必須 | `lua` と `data` を含むフォルダ全体 |
| root権限 | root環境のみ | GameGuardianが対象プロセスを読める状態 |
| 仮想空間アプリ | 仮想空間のみ | にゃんこ大戦争とGameGuardianを同じ空間で起動できるもの |
| Vector / Hide My Applist | 任意 | root端末でアプリ一覧の可視性を管理したい場合 |

## 最初に行うこと

1. GitHubの **Code → Download ZIP** から、このリポジトリをダウンロードします。
2. ZIPを展開します。
3. 展開した `KBC-GGscript` フォルダを、端末の内部ストレージへコピーします。
4. 次の構成になっていることを確認します。

```text
内部ストレージ/
└─ KBC-GGscript/
   ├─ data/
   │  ├─ status-fields.csv
   │  ├─ unit-index.csv
   │  └─ units/
   ├─ lua/
   │  └─ KBC-GGscript.lua
   ├─ settings/
   └─ status-saves/
```

`KBC-GGscript.lua` だけを移動すると、キャラ名・ステータス定義を読めません。必ずフォルダごとコピーしてください。

## KBC GameGuardianをインストールする

GooglePixel8(Android15) root環境で動作するよう改良されたものです。
他の機種で動作するか確認していません。
このスクリプトは、KBC GameGuardianでの利用を想定しています。確認済みの端末環境は次の通りです。

| 項目 | 確認済みの値 |
| --- | --- |
| パッケージ名 | `com.KBC.ggnyanko` |
| バージョン | `101.1` |

APKは [downloads/KBC-GameGuardian-v101.1.apk](downloads/KBC-GameGuardian-v101.1.apk) に同梱しています。


1. APKを端末へ保存します。
2. ファイル管理アプリでAPKをタップします。
3. 表示された場合は、そのファイル管理アプリに対して「不明なアプリのインストール」を許可します。
4. インストール後、KBC GameGuardianを一度起動します。
5. Androidの設定で、KBC GameGuardianに次の権限を許可します。

   - 他のアプリの上に表示
   - 写真と動画／音楽と音声、またはストレージへのアクセス
   - 通知（任意）

6. root環境では、root管理アプリに表示されるKBC GameGuardianのroot権限要求を許可します。

アプリが開けない、またはインストール時に「パッケージの解析中に問題が発生しました」と表示される場合は、APKを取り直し、端末のAndroidバージョン・CPUアーキテクチャに対応しているか確認してください。

## root環境で使う

### 1. 事前確認

- root管理アプリでrootが有効であることを確認します。
- にゃんこ大戦争を一度起動して、タイトル画面まで進めます。
- KBC GameGuardianを通常のAPKとしてインストールし、root権限の要求を許可します。
- Androidの設定で、KBC GameGuardianの「他のアプリの上に表示」とストレージへのアクセスを許可します。

### 2. スクリプトを起動する

1. にゃんこ大戦争を起動したままにします。
2. KBC GameGuardianを開き、プロセス選択からにゃんこ大戦争を選びます。
3. KBC GameGuardianのファイル実行(▶)から、次を開きます。

   ```text
   /storage/emulated/0/KBC-GGscript/lua/KBC-GGscript.lua(保存スクリプトのパスを指定)
   ```

4. ホーム画面から使いたい機能を選びます。

### 3. root環境で失敗した場合

最初に、対象アプリを正しく選んでいるか確認します。それでも「libnative-lib.so」や保存配列に関するエラーが出る場合は、次の順に試してください。

1. にゃんこ大戦争を完全終了します。
2. KBC GameGuardianも終了します。
3. にゃんこ大戦争を起動してからKBC GameGuardianで対象を選び直します。
4. スクリプトを最初から実行します。

Androidの版やroot方式によって、ライブラリのメモリ範囲の表示が異なります。スクリプトは複数の範囲を順に検証しますが、ゲーム更新後は対応できない場合があります。

## 仮想空間で使う

仮想空間はrootなしで使える場合がありますが、アプリ・Android版・仮想空間の実装ごとに挙動が異なります。

### 1. 仮想空間を準備する

1. 仮想空間アプリをインストールします。
2. **にゃんこ大戦争とKBC GameGuardianを同じ仮想空間へ追加**します。
3. 仮想空間内でにゃんこ大戦争を起動します。

### 2. 実行する

1. 仮想空間内のKBC GameGuardianを開きます。
2. 仮想空間内で動いているにゃんこ大戦争を対象として選びます。
3. 仮想空間内から `lua/KBC-GGscript.lua` を実行します。

### 仮想空間の注意点

- ホスト側のKBC GameGuardianではなく、仮想空間内のKBC GameGuardianを使います。
- ホスト側にあるフォルダを仮想空間から読めない場合があります。その場合は仮想空間のファイル管理画面でフォルダ全体をコピーしてください。
- メモリ範囲・64bit対応・ファイル権限は仮想空間ごとに異なります。root環境で動くことが、仮想空間でも動くことを保証するものではありません。

## 任意: Vector と Hide My Applist

Vectorはroot端末向けのXposed互換フレームワーク、Hide My Applistはアプリ一覧の可視性をアプリごとに管理するモジュールです。どちらもこのスクリプトの実行には必須ではありませんが、エンドフィールドのようなGGをインストールしているとアンチチートによりアプリを開けなくなる問題を解決できます。

### 導入前の注意

- rootモジュールの導入前に、端末が正常起動する状態をバックアップしてください。
- モジュールは公式の配布元から入手してください。
- 問題が起きたときに切り分けられるよう、VectorとHide My Applistを同時に初めて導入せず、1つずつ再起動・確認します。
- モジュールを有効にする対象範囲は必要最小限にします。システム全体へ無差別に適用しないでください。

### Vectorの導入

1. [Vectorの公式リリース](https://github.com/JingMatrix/Vector/releases)から、使用中のroot方式に対応したモジュールを取得します。
2. root管理アプリを開き、モジュール追加画面から取得したZIPを選びます。
3. インストールが完了したら再起動します。
4. 再起動後、Vectorの管理画面または通知から、フレームワークが有効であることを確認します。
5. 起動不良が起きた場合は、root管理アプリから直前に追加したモジュールを無効化して再起動します。

### Hide My Applistの導入

1. [Hide My Applistの公式リポジトリ](https://github.com/Dr-TSNG/Hide-My-Applist)の案内を確認し、配布されているAPKをインストールします。
2. Vectorのモジュール管理画面でHide My Applistを有効にします。
3. 適用範囲を確認し、アプリ一覧を管理する必要があるアプリだけに限定します。
4. 変更後は対象アプリを再起動し、通常の動作に問題がないか確認します。

トラブルが起きた場合は、まずHide My Applistの適用を外し、次にVectorのモジュールを無効化して、どの段階で問題が起きるか切り分けてください。

## 基本操作

### キャラ解放/Lv変更/形態変更

- `一覧から選ぶ` はIDを100件ごとに分けて表示します。
- `キャラ名/IDで検索` は第1～第4形態の名前でも検索できます。
- `全キャラ` は大量の保存値を書き換えます。実行前に必ずバックアップしてください。
- `凍結` をオンにすると、GameGuardianの保存リストへ値を登録します。不要になったら同じ項目を凍結なしで変更して解除します。

### ステータス変更

ホームの `設定` で表示方式を選べます。

- **長い一覧**: 117項目をまとめて表示します。
- **index範囲**: `0～19`、`20～39` のように20項目ごとに表示します。

画面外をタップした場合は、GameGuardianのアイコンを押すと同じ編集画面を開き直します。`戻る` を押した場合は1つ前の画面に戻ります。

### ステータスの保存と読み込み

ステータス変更画面の `保存` は、変更済みの項目だけを次の場所へ保存します。

```text
KBC-GGscript/status-saves/
```

`保存したステータスを読み込む` から、同じキャラ・形態に保存した内容を選んで適用できます。

## フォルダ構成

| パス | 用途 | 編集の可否 |
| --- | --- | --- |
| `lua/KBC-GGscript.lua` | 実行するスクリプト | 編集非推奨 |
| `data/unit-index.csv` | キャラID・形態名 | 更新時のみ |
| `data/units/` | ユニットの基礎値 | 更新時のみ |
| `data/status-fields.csv` | ステータス名・入力形式・倍率 | 上級者向け |
| `settings/` | 表示設定 | 自動作成・自動更新 |
| `status-saves/` | 保存したステータス | 自動作成・自動更新 |

## 更新方法

1. `status-saves` フォルダを別の場所へコピーしてバックアップします。
2. リポジトリの最新版をダウンロードして展開します。
3. 既存の `KBC-GGscript` を置き換えます。
4. バックアップした `status-saves` を新しいフォルダへ戻します。
5. にゃんこ大戦争とGameGuardianを再起動してから実行します。

ゲームが更新された場合は、Luaだけでなく `data` も同じリリースの組み合わせで置き換えてください。

## 困ったとき

| 表示・症状 | 確認すること |
| --- | --- |
| `ユニットデータを取得できない` | `data` を含むフォルダ全体をコピーしたか、`data/units/unit000.csv` があるか確認します。 |
| `libnative-lib.so` / 保存配列を取得できない | にゃんこ大戦争を先に起動し、GGの対象アプリを選び直します。ゲーム・GGを再起動して再試行します。 |
| ステータスが違うキャラのものに見える | スクリプトを終了してゲームを再起動し、同じバージョンの `data` を使っているか確認します。 |
| 保存に失敗する | `KBC-GGscript/status-saves` を作成し、GGにストレージ権限を許可します。 |
| 画面外タップ後に表示されない | GGのオーバーレイアイコンを押します。必要ならGGの「他のアプリの上に表示」を確認します。 |
| root環境でGGが対象を読めない | root権限の許可、対象の選択、root管理アプリ側の拒否設定を確認します。 |
| 仮想空間でファイルが見えない | 仮想空間の内部ストレージへ `KBC-GGscript` フォルダ全体をコピーします。 |

不具合があれば私に連絡してください。
